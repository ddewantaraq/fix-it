# Why Iklim PAL is not an anti-project

Hackathon bans include: basic RAG, simple AI-for-education chatbots, anything political, simple image analyzers.

| Risk | How Iklim PAL avoids it |
| --- | --- |
| Basic RAG | No vector DB or climate-PDF corpus. Knowledge = Action Pack JSON + Muse tools. |
| AI education chatbot | Success artifact is a **measurable Action Plan**, not a climate quiz or definition tutor. |
| Political | Community litter cleanup only — no parties, lobbying, protest logistics, or voting advice. |
| Simple image analyzer | SAM grounds evidence; Spark runs a multi-step tool loop; Wonder synthesizes the plan; Muse Image makes a share card. Captioning alone is never the product. |

Judge line: *Iklim PAL turns a local litter concern into a pack-approved, safety-bounded youth action plan using Muse models as tools inside a rules agent.*
